# StockPilot AI

Advanced Offline Inventory Management System built with HTML, CSS, and JavaScript.

## Features

- Dashboard with live inventory KPIs
- Product management
- Stock in, stock out, and stock adjustment
- Purchase orders and stock receiving
- Sales orders with automatic stock deduction
- Customer, supplier, and warehouse management
- Reports and monthly sales visualization
- Rule-based offline AI Inventory Copilot
- Low-stock notifications
- Audit logs
- JSON backup/export
- Browser Local Storage persistence
- Responsive interface

## Run Locally

No backend, database server, npm package, or API key is required.

1. Download or clone the repository.
2. Open `index.html` in a browser.
3. For the best development experience, use VS Code Live Server.

## Important Note

This repository is an offline/local-first academic project. The AI Copilot uses predefined business rules and inventory calculations; it is not connected to an external LLM or cloud AI API.
